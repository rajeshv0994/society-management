## Status terminology

- **Done**: implemented in source, wired to persistence/API, and available through the
  relevant application or Swagger.
- **Partial**: a useful part exists, but one or more required UI, backend, automated test,
  or external integration pieces are missing.
- **Pending**: no complete usable workflow exists.
- **External integration**: the internal model/workflow exists, but a third-party service
  must be connected before production use.

The status is a repository snapshot, not a product promise. Update
`FEATURE_STATUS.md` in the same change whenever a feature is completed or its scope changes.
